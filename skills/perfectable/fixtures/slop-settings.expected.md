# slop-settings

Detector exits 2. Expect `modal-preferences` (the file name is settings and the root is a dialog) and `equal-pane-grid`.

A layout pass also names:

- Settings is a grouped form, not a dashboard of equal metric cards.
- Preferences are a window or a panel, not a dialog over the editor.
- One 16px interval for both the grid and the cards. Groups need the group role; fields inside a group need the control role.
