# Quiet

Reduce chrome noise in a tool or dashboard without flattening hierarchy or turning density into a website. This is the desktop equivalent of a quieter pass.

## When

The window is loud: saturated accent on inactive rows, competing weights, decorative motion, glass on the data, a shadow under every panel.

## Procedure

1. List the intensity: accent used as a wash, more than one elevation on a surface, motion that is not state, type sizes that jump like a marketing ramp.
2. Leave one accent for selection, the primary action, and real state. Neutrals do the rest. Secondary text stays mixed from the surface, not a raw gray on color.
3. Keep two spacing roles. Quiet does not mean one generous padding everywhere. Chrome stays at the platform row metric. Air stays in the sovereign surface.
4. Remove decorative motion. Keep the state change (selection, dirty, expand) and honor reduced motion.

## Refuses

- Making every label the same weight. Hierarchy still needs one step.
- Removing the accent entirely so state disappears.
- Growing chrome padding to "add calm."
- A grayscale theme that ignores the platform's high contrast.

## Verify

The task is easier to scan for a long session. The composition id did not change. Hand off to `polish`.
