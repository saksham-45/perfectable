# Amplify

Raise one region of a tool or dashboard to the conviction the rest of the chrome already implies. This is the desktop equivalent of a bolder pass. It is not a marketing hero, a new palette, or a louder accent on every card.

The world already shipped. Touch only the named target. Product facts stay in APP.md. Do not move them into CHROME.md to "make the number bigger."

## When

The user says the window is flat, timid, or that one instrument does not read as the point. A direction that has not been chosen yet belongs to `shape`, not here.

## Procedure

1. Read APP.md, CHROME.md, and the composition. Name the one region that should be the peak: the sovereign surface, one status, or one primary figure.
2. Find the strongest move the existing chrome already owns (weight, the accent used once, the type step, the inset). Bring the target up to that move. Do not import a new color, face, radius, or shadow.
3. Quiet the neighbors so the peak is legible. If every card got larger, the window got flatter.
4. Keep claims true. A bigger number is still the same number.

## Refuses

- A new visual system.
- Equal amplification of every metric.
- Gradient text, glow, or a pulsing dot as the boldness.
- Display type in a toolbar, tree, or status line.
- Replacing the composition with a centered hero.

## Verify

The named target is the first thing the squint test names. Everything outside it is unchanged. Hand off to `polish` when the peak holds.
