# Materials

Assign layers, tokens, and elevation using [canon/materials.md](canon/materials.md) and the platform file's material section. Do not restate the layer model here.

## Procedure

1. List each surface as content, functional, or transient.
2. Map the token names in the canon onto the project's existing tokens. Missing CHROME.md: run `document` if chrome already exists; otherwise record the map in the edit and let `document` carbonize it after.
3. Put the platform material only on the functional and transient layers. Content stays solid.
4. Check light, dark, and high contrast together: text, secondary text, boundaries, focus, selection, find, error. Thresholds are the craft floor.
5. Remove the second elevation when a surface has both a border and a soft shadow, unless CHROME.md already chose one and the other is a platform separator the toolkit draws.
6. Fix in one batch. Confirm once. Stop.

A request to "add color" or "make it calmer" is this command. The accent still marks selection, the primary action, and state. It does not become a theme.

Hand `layout` back when the materials are right and the space is still flat.
