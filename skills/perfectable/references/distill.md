# Distill

Strip a tool or dashboard to the one job. Remove chrome that does not earn its place. This is not a feature cut and not a simpler website.

## When

Too many equal regions, repeated labels, nested cards, a metric wall, two navigation systems, or a toolbar that repeats the menu.

## Procedure

1. Name the one primary object from APP.md. If that sentence is missing, stop and return to `init`. Do not invent the job inside the visual pass.
2. Keep the sovereign region. Demote everything else: a supporting number becomes a row or a status cell, not a peer card.
3. Delete a container that only existed to group things proximity already groups. Progressive disclosure (a menu, a disclosure, an inspector) hides the rare command. It does not become a modal in front of the work.
4. One primary action in the command band. The rest move to the menu they already belong to.

## Refuses

- Removing undo, focus, names, or the recovery path to look cleaner.
- Replacing a dense table with a marketing stack "so it breathes."
- A mystery-meat icon row with no labels.
- Nesting the remaining groups inside a new card.

## Verify

The squint test names one sovereign region. A necessary command is still one keyboard step away. Hand off to `layout` if the intervals collapsed into one role, otherwise to `polish`.
