# First run

Get a tool or dashboard to the first useful state. Empty panes and first launch are this command. A tour that blocks the window is not.

## When

First launch, an empty list, no results, a permission failure, or a crash-restored window with nothing open. Distinguish those. They are not the same sentence.

## Procedure

1. Put the empty state in the sovereign pane, aligned with that pane's text edge. Do not center a marketing hero in the window.
2. The sentence names what will appear here and the next action, as a real control ("Open a file", "Clear the filter"), with a shortcut if the command has one.
3. First launch may ask for the one fact the product cannot assume. Experienced users skip it. Do not teach the menu bar.
4. No-results offers a way back (clear filter, widen the query). Permission failure says who can grant it. Load failure offers retry. Do not celebrate.

## Refuses

- A forced multi-step tour before the window is usable.
- A pulsing illustration, a gradient wordmark, or a pill CTA that bypasses the system file dialog.
- Sample numbers presented as the user's data.
- The same coach mark on every launch.

## Verify

Jordan can name the next action in a few seconds. Alex can dismiss and reach the real command. Hand off to `clarify` if the words are still vague, otherwise to `polish`.
