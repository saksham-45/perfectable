# Layout

Fix structure, intervals, and alignment. Load [canon/layout-geometry.md](canon/layout-geometry.md) and [canon/compositions.md](canon/compositions.md). Load the platform file `context.mjs` named. Do not restate those files here.

A complaint about spacing, alignment, empty space, hierarchy, or "it feels like a website" is this command. A wrong workspace thesis goes to `shape` before any CSS.

## Procedure

1. Read APP.md, CHROME.md, and the composition catalog. If the thesis or the composition is missing or wrong, stop and hand back to `shape`. Do not restyle a wrong structure.
2. Write the spatial contract before editing: composition id, sovereign surface, which spacing roles are in use, where air goes, what collapses at the compact width.
3. Pass A, visual, without the detector: squint test, grouping, rhythm (at least two roles), density versus posture, spread, the extremes list in the geometry file.
4. Pass B: run `detect.mjs` on the target. Then look for overflow, stacking, and a single gap value the scanner cannot prove. Keep the two passes separate until both exist.
5. Edit structure first (which region exists, what sits in it, what collapses), then intervals, then the optical pass on a screenshot.
6. Verify compact, regular, and wide, light and dark, in one round. Fix that round in one batch. Confirm once. Stop.

Hand `typeset` the type ramp if that is the remaining defect. Hand `polish` the window when the structure holds.

## Contract shape

```text
composition: three-pane
sovereign: detail
roles: tight in the row, control in the toolbar, group between list sections, inset in the detail
air: detail measure; list stays dense
compact: sidebar collapses; list and detail remain
```

## Done

The squint test names the sovereign surface first. Two interval sizes are visible. Air is in that surface. A screenshot has had the optical pass. The detector's layout findings on the touched files are fixed or explicitly ignored.
